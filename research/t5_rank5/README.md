# Rank-5 exclusion of |T>^5: feasibility probes

Measurements behind `docs/notes/t5_rank5_feasibility.md`. Nothing here is
a bound; the pipeline itself (stages alpha, beta', gamma at the single
base point 00) is designed in the note and not yet built.

- `run.py`: runs one command at nice 19 in its own session under a
  wall-clock cap, killing the process group at the cap (macOS has no
  `timeout`). `run.py --max-seconds 600 -- research/t5_rank5/probe.py CMD`.
- `probe.py`: the probes, one subcommand each (`flats`, `census5`,
  `degenerate5`, `rates`, `beta-rate`, `census4`, `products4`, `rank2`,
  `rank2-aggregate`); each writes a record under `results/`.
- `rank2_loop.sh`: the full rank-2 residual table in ten capped runs.
- `results/`: the records named in the note. `census5_full.json` holds
  the per-pivot-pair counts of the full 5-cover census of |T>^3 (the
  covers themselves are regenerated by the kernel); `degenerate5.json`
  holds the 43,773 dependent and repeated-state 5-multisets.

Run from the repository root through `uv run --extra challenge python`
(the runner does this for `.py` commands).
