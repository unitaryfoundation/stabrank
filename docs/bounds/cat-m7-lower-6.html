Participate

Run it yourself, or point a coding agent at it.

git clone https://github.com/unitaryfoundation/stabrank
cd stabrank
# describe your decomposition in bounds/mybound.json
make fit BOUND=bounds/mybound.json ARGS=--write
make verify BOUND=bounds/mybound.json

fit solves for the exact coefficients, or tells you no exact combination of your terms reproduces the target. verify rebuilds the identity in exact arithmetic. If it passes, open a pull request adding the file and the leaderboard picks it up on the next build.

A bound the pipeline cannot check is recorded as cited and never takes a record.

Notes

With bounds/cat-m7-upper-6.json, χ(cat_7) = 6; improves bounds/cat-m7-lower-5.json (attested). First found 2026-09-17 by a floating-point run of the same argument (stabrank-research round 10, about 33 CPU-hours, mostly the five-qubit projected ranks); this certificate redoes it exactly in about 200 s on one core. Projection lemma on compressed c7 (six qubits): a term stabilised by g forces χ((1-g)c7) ≤ 4, two terms sharing g force ≤ 3, three force ≤ 2. Projected ranks come from the same exclusion one qubit down, recursively to three qubits (all 1080 states): ≥ 5 on 6524 signed Paulis, ≥ 4 on 1526, ≥ 3 on 140, one representative per orbit of <S7, J0 J1 (J = X S^dagger), K = S^(x)7 o conj> (12 orbits, generators asserted to fix c7; point stabilisers transported to five qubits via Schreier generators). Cheap set 1666, vocabulary 1088 states (every signed group inside it, each once), 3968 pivot triples after symmetry and the pair/triple constraints, no decomposition. Exactness: entries in Z[i], ranks mod P1 = 2147483629 and P2 = 2147483549 (both 1 mod 4); independence mod either prime is independence over Q(i), and a deficiency counts only below Hadamard's bound (P1, or P1 P2 for the 6x6 pair test). No floating-point value anywhere, enumeration and symmetry included. Controls in the run: χ(c5) = χ(c6) = 3 recovered by the same prover (it finds rank-3 decompositions when asked for 4); a planted unit sum of five compatible vocabulary states is excluded at rank 4 and found at rank 5. The counts (orbit sizes, 140/1666 cheap, 1088 states, 13 to 88 five-qubit orbits) match the September run.
