Run it yourself, or point a coding agent at it.

git clone https://github.com/unitaryfoundation/stabrank
cd stabrank
# describe your decomposition in bounds/mybound.json
make fit BOUND=bounds/mybound.json ARGS=--write
make verify BOUND=bounds/mybound.json

fit solves for the exact coefficients, or tells you no exact combination of your terms reproduces the target. verify rebuilds the identity in exact arithmetic. If it passes, open a pull request adding the file and the leaderboard picks it up on the next build.

A bound the pipeline cannot check is recorded as cited and never takes a record.

Verification

verified   12 stabilizer terms reproduce |N>^{ot 5}, checked symbolically

Implied per-copy exponent γ ≤ 0.4524 against a published 0.4206, no improvement.

Compute

1 run; 0.001 CPU-hours; 0.001 h wall-clock; on Apple silicon laptop, one core; direct construction, no search.

Notes

Tensor product of the exact decompositions research/constructions/data/N_m2_rank3.json (decomposition 0 of 30, coefficients fitted exactly by fit_coeffs.fit), research/constructions/data/N_m3_rank4.json (decomposition 0 of 1, coefficients fitted exactly by fit_coeffs.fit): χ(|N⟩⊗2) ≤ 3 x χ(|N⟩⊗3) ≤ 4 gives χ(|N⟩⊗5) ≤ 12, exponent 0.4524. First witness for this cell; it is the sub-multiplicative value the board already implied and does not move the exponent. Terms are the exact products (x0 and l concatenated, W and Q block diagonal) and coefficients the exact products, built by research/constructions/product_witness.py.
