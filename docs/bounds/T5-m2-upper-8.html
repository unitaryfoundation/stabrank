Run it yourself, or point a coding agent at it.

git clone https://github.com/unitaryfoundation/stabrank
cd stabrank
# describe your decomposition in bounds/mybound.json
make fit BOUND=bounds/mybound.json ARGS=--write
make verify BOUND=bounds/mybound.json

fit solves for the exact coefficients, or tells you no exact combination of your terms reproduces the target. verify rebuilds the identity in exact arithmetic. If it passes, open a pull request adding the file and the leaderboard picks it up on the next build.

A bound the pipeline cannot check is recorded as cited and never takes a record.

Notes

Found by autoresearch/run.py on seed 7002 after 0 failed seed(s) at this rank (residuals none); the exact coefficients were recovered by fit_coeffs.fit and the identity is checked symbolically by the verifier. Implied γ log_5(8)/2 = 0.6460, below the single-copy product bound log_5(3) = 0.6826 that is the orbit's baseline (no exponent has been published for any p = 5 state). Puts the cell at 5 ≤ χ(|T5⟩⊗2) ≤ 8 with the rank-4 exclusion of cert_t5_m2_rank4.py, against the product bound 9 from χ(|T5⟩) = 3. Short annealer probes at ranks 4 to 7 plateaued at residuals 0.385, 0.311, 0.31 to 0.32 and 0.227, so ranks 5 to 7 are open. Every run is logged in autoresearch/runs.jsonl.
