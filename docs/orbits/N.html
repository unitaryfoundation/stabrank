Run it yourself, or point a coding agent at it.

git clone https://github.com/unitaryfoundation/stabrank
cd stabrank
# describe your decomposition in bounds/mybound.json
make fit BOUND=bounds/mybound.json ARGS=--write
make verify BOUND=bounds/mybound.json

fit solves for the exact coefficients, or tells you no exact combination of your terms reproduces the target. verify rebuilds the identity in exact arithmetic. If it passes, open a pull request adding the file and the leaderboard picks it up on the next build.

A bound the pipeline cannot check is recorded as cited and never takes a record.

The state

|N⟩=|0⟩+|1⟩−2|2⟩6

The Norrell state. Real amplitudes, one of them twice the others in magnitude, so unlike T3 its amplitudes are not all of equal modulus.

Shares the published exponent log₃4/3 with H₃. Its m=4 cell sits at 7; rank 6 bottoms out at √(211/4043) across five of six independent anneals, with a deeper basin at √(419/8559).
